# 🚀 Space Defender

An exciting browser-based space shooter game built with HTML5 Canvas and vanilla JavaScript!

## 🎮 Features

- **Smooth Gameplay**: 60 FPS action with fluid controls
- **Progressive Difficulty**: Enemies get faster and spawn more frequently as you level up
- **Beautiful Graphics**: Modern UI with gradient effects and particle systems
- **Responsive Design**: Works on different screen sizes
- **Score System**: Track your progress with score and level indicators

## 🕹️ How to Play

1. Open `index.html` in your web browser
2. Use **Arrow Keys** (← →) to move your spaceship
3. Press **SPACE** to fire bullets at enemies
4. Destroy enemies to earn points
5. Avoid collisions - you have 3 lives!
6. Level up every 100 points

## 🛠️ Technical Details

- **Pure Vanilla JavaScript**: No frameworks or libraries required
- **HTML5 Canvas API**: For rendering graphics and animations
- **CSS3**: Modern styling with gradients, animations, and backdrop filters
- **Particle System**: Dynamic visual effects for explosions
- **Collision Detection**: Rectangle-based collision algorithm

## 🎨 Code Structure

- `index.html` - Game layout and UI elements
- `styles.css` - Modern styling with animations
- `game.js` - Game logic, rendering, and controls

## 🚀 Running the Game

Simply open the `index.html` file in any modern web browser:

```bash
# If you have Python installed, you can run a local server:
python3 -m http.server 8000

# Then open http://localhost:8000 in your browser
```

## 🎯 Game Mechanics

- **Score**: +10 points per enemy destroyed
- **Level Up**: Every 100 points
- **Lives**: Start with 3 lives
- **Enemy Speed**: Increases with each level
- **Spawn Rate**: Enemies spawn more frequently at higher levels
